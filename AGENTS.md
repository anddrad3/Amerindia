# Fluxo de trabalho

- Quando o usuário solicitar alterações neste projeto, implemente e faça as verificações pertinentes; depois crie um commit e envie-o para `origin` no GitHub (`anddrad3/Amerindia`). Essa rotina foi autorizada pelo usuário.
- Inclua no commit apenas as alterações relacionadas ao pedido e preserve trabalhos locais não relacionados.
- Não use force push. Se houver mudanças remotas, integre-as preservando o trabalho local antes de enviar.
- Ao concluir, informe o que mudou, a verificação realizada e o resultado do envio ao GitHub. Se a autenticação ou outro impedimento bloquear o envio, deixe isso explícito.
