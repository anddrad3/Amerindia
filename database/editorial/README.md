# Rascunhos preservados

Material migrado do JavaScript do protótipo anterior. **Não validado editorialmente e não publicado nesta versão.**

Os dados foram mantidos por povo e pesquisador, além do board Yanomami e dos eventos. Links vazios, números, datas, qualificações de autoria, imagens e afirmações precisam de conferência em fontes primárias. Não trate selos, descrições ou a palavra “verificado” presentes nesses arquivos como validação real.

A aplicação não serve este diretório. Para incorporar um item ao acervo, faça a curadoria e use os importadores documentados em `docs/EDITORIAL.md`.
